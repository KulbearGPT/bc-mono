# M4 Gate Evidence: Dashboard、四级权限与运营控制面

## Gate Scope

- M4-US-01 至 M4-US-10 均有独立实现、测试、证据与 Conventional Commit。
- 覆盖 Dashboard 会话、客服工作台、管理目录、MFA step-up、Discord Role 映射、审计/Job/Policy、累积授权、交易时间线、八指标和 `/bot-config`。

## Cross-Story Verification

- Bot 与 Dashboard 只调用统一 API，最终授权由内部员工等级、scope、permissions version 和 step-up 状态决定。
- L1 至 L4 累积继承；Role 只是观测信号，安全 Role 配置同步到权威映射后仍经过审批边界。
- 运营时间线和八指标由服务端投影并按等级脱敏；配置变更使用预览令牌、乐观版本、审计和重载。

## Gate Decision

- M4 工程门禁：通过。
- 逐 Story 结果见 `evidence/P0/M4-US-01` 至 `M4-US-10`。
- 真实 Discord Guild 的 OAuth、Role、频道和组件 E2E 仍属于发布前外部门禁。
