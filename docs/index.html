当前不可混淆的运行边界

CAT 是内部唯一账本

固定 1 USD = 10 CAT、1 USD cent = 1 CAT subunit。USD 只用于充值凭证和线下结算辅助，不连接支付 Provider。

候选池，不是自动派单

合格陪玩报名或撤回，客户完成终选；退役的自动派单开关、轮数和超时配置不得恢复。

全陪玩逐名就绪

客户只读查看进度。所有当前有效陪玩分别确认本人就绪后，API 才原子进入服务中。

统一 API 与可信 Actor

Bot 和 Dashboard 不决定最终权限、金额、Guild 归属或状态；Discord Role 也不是授权事实。

只追加与可恢复

资金、订单事件、收益、返佣、配置和审计只追加；Worker 重放沿用原幂等键，不重复业务写入。

历史证据不是当前合同

M0–M6 证据可能描述后来退役的 Provider、自动派单或双边 readiness。它们保留审计价值，但不能恢复为当前设计。
