# 黑猫陪玩项目横幅

本目录包含目录中 13 个项目的横向 WebP 横幅。图片以 `../brand/mascot-character-reference.png` 作为唯一角色母版；统一采用中性蓝调傍晚、青蓝与暖金光效、2:1 构图和圆润标题字体。运行时版本统一为 `1600×800`、WebP quality 84，以减少 Discord 附件上传和 CDN 展示延迟。文件名、显示名和资源路径只以 `manifest.json` 为准；目录新增、重命名或下架时必须同步 manifest、消费者测试和消息 fallback。

## 生成提示词

公共模板：

## 运行时边界

- 横幅只增强目录识别，不携带价格、资格、余额、候选或订单状态；这些事实必须来自统一 API。
- Discord 上传、CDN 或附件读取失败时，消息仍需用文字显示项目名与下一步。
- 不因主题相似而复用第三方商标、角色或宣传素材；生成来源不改变版权检查责任。
