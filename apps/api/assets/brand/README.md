## 固定角色特征

- 圆润短身、较大的圆头、短腿小爪和蓬松黑色短毛。
- 超大圆形金色眼睛、小鼻子、小嘴和紧凑猫脸；不得拉成长脸或类人比例。
- 头顶是两耳之间的自然圆滑短绒轮廓，**禁止头顶毛束**、马尾、冠毛、莫西干或从耳机中伸出的蓬松形状。
- 角色只有一条粗而蓬松的尾巴，**尾巴从后腰连接**，可从身体后方向上卷起；不得把正面设定图中露在头后的尾巴误画成头发。
- 耳机、披风、围巾、护具和游戏道具都是可拆配件，不得改变脸型、眼睛比例、身形或尾巴连接位置。

## 视觉规则

- 通用基调为中性蓝调傍晚：深海军蓝、长春花蓝、青蓝和暖金；避免大面积纯黑，也避免粉色、花朵和浪漫装饰主导画面。
- 可爱感来自角色比例、表情、圆角物件和圆润标题字体，不依赖性别化配色。
- 标题必须逐字使用目录显示名，只出现一次，并在 Discord 手机宽度保持清晰。
- 不复制游戏官方 Logo、角色、地图、皮肤或宣传图；只使用原创通用题材元素。
- 新资产必须记录用途、尺寸、格式和运行时 fallback；装饰图使用空替代文本，传达内容的图必须提供等价文字。
