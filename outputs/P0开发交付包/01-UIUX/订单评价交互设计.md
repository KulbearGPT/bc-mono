# Discord 完单评价交互设计（M21）

## 1. 目标与边界

- 订单完成后只提供一个“评价本次服务”入口；所有评价均为可选，不阻塞离开频道、再次下单或任何资金结算。
- 评价对象由统一 API 返回：订单整体、每位有效陪玩，以及确实产生本单首次客服响应时的“猫舍前台”。Discord 不接受或拼装任意陪玩、员工或用户 ID。
- 星级点击成功即保存且不可编辑；留言始终可选。用户随时关闭 ephemeral 面板，已成功保存的星级不丢失。
- 保存五星不等于公开。只有用户看过五星安全预览并明确点击“同意公开五星好评”，才请求发布。

## 2. 最短路径

完成卡只增加一个次要按钮：`评价本次服务`。

打开后的第一屏优先展示订单整体，并直接提供五个星级按钮：

```text
这次服务怎么样？                 订单 P-12345678
订单整体                         尚未评价
[1 星] [2 星] [3 星] [4 星] [5 星]

陪玩与猫舍前台（3 个可选对象）
[选择其他评价对象]
```

用户点击任一整体星级后，Bot 先 defer/update，API 成功才将该行改为 `已保存：★★★★★`。这是打开评价中心后的唯一必需点击；此后可直接离开。

## 3. 多陪玩与不同分数

“选择其他评价对象”打开 API 返回的未评价目标 Select，目标标签只显示公开安全名称：

- `陪玩 · 小黑`
- `陪玩 · 小白`
- `陪玩 · 小橘`
- `猫舍前台`（仅真实客服首响存在时）

用户可一次选择一个或多个目标，随后点击一至五星按钮给所选对象相同分数。API 在一个事务中验证整组 `targetKeys`，任一失效则整批零写入并刷新最新中心。需要不同分数时，用户重新选择剩余未评价对象即可；已评价对象不再出现在可写 Select 中。

典型点击数：

| 需求 | 打开后点击数 | 结果 |
|---|---:|---|
| 只评订单整体 | 1 | 整体星级立即保存 |
| 三位陪玩同分 | 2 | 多选三人，再点一次共同星级 |
| 两位好评、一位差评 | 4 | 多选两人并点星级，再选择一人并点另一星级 |
| 不想评价 | 0 | 直接关闭，业务事实不变 |

目标超过单页 Select 容量时，API 返回稳定分页状态；上一页、下一页和已选上下文使用签名消息状态或 API 游标，不使用 Bot 进程内 Map。

## 4. 留言与低分体验

每个已保存目标旁只显示一个次要动作 `补充留言（可选）`。点击后打开最多 500 字的新 Modal；提交成功后显示 `已收到留言`，不回显私密全文。

一至二星同样立即保存，不增加原因选择或其他前置步骤；P0 只保留可选留言。用户关闭 Modal、Modal 超时或留言写入失败时，已保存星级保持不变。

同目标重复评分或旧组件冲突时，Bot 不自动重放原星级意图，只读取并展示 API 当前事实和 request ID。

## 5. 五星公开预览与明确同意

存在至少一个已保存五星目标时，评价中心显示次要动作 `预览可公开的五星好评`。预览只能包含：

- 订单公开编号、游戏/服务名称、完成时间、阵容人数；
- 获得五星的对象类型与安全展示名；客服只显示“猫舍前台”；
- 固定五星图形，不包含用户自由留言。

预览底部使用两个明确动作：`同意公开五星好评` 与 `仅内部保存`。只有前者调用发布 API；后者和关闭面板均零公开写入。发布后本单不再出现第二个发布动作。

公开卡只投递到同 Guild Bot 配置中的 `review_broadcast_channel_id`（后台显示为“好评展示频道”）。该字段使用 Discord 频道选择/校验和“发送频道验证消息”能力；缺失、跨 Guild 或 Bot 无发言权限时失败关闭，不回退到订单频道或礼物播报频道。

混合评价示例：订单整体五星、陪玩 A 五星、陪玩 B 四星、陪玩 C 一星且有留言。公开卡只展示“订单整体五星”和“陪玩 A 五星”，不得通过人数、占位符或“另有评价”等文字暗示 B、C 的评分、留言或是否被评价。

## 6. 失败、隐私与恢复

- 所有中心、成功、失败和预览反馈均为 ephemeral；公共频道只接收 API 创建的明确同意五星快照。
- 不公开一至四星、低分原因、留言、未评价或非五星对象、客户身份、价格、钱包、订单私密备注、私密频道或内部客服身份。
- API 请求前先 ACK；网络、非 JSON、5xx 和冲突返回具体操作、写入确定性、下一步与 request ID。
- Worker 只按稳定发布 ID 和 Outbox 重试同一快照；消息缺失时恢复，不重复评价、发布或业务写入。
- 评价及其失败不自动影响派单、准入、收益、权限、处罚、订单状态或资金。

## 7. 验收映射

- `INT-D-M21-001` / `AT-REVIEW-001`：合法目标、全部可选、无客服首响时不出现客服。
- `INT-D-M21-002` / `AT-REVIEW-002`：一键整体评价、多选同分、分别打分、可选留言、重启恢复。
- `INT-D-M21-003` / `AT-REVIEW-003`：明确公开同意、混合评价只播五星、Outbox 幂等。
- `AT-REVIEW-004`：评价与订单、资金、收益、返佣及权限事实隔离。
