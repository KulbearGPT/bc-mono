## 6. 外部证据登记与完成条件

每个验收 ID 必须分别保存以下信息：

- 最终候选完整 Git SHA，且必须与发布配置中的 `releaseCandidate` 完全一致；
- 具名执行人、角色、设备、环境与 UTC 时间；
- 实际步骤、预期结果、实际结果和结论；
- request ID、脱敏截图/录屏、日志或只读对账文件及 SHA-256；
- 失败场景的诊断信息和清理结果。

结果必须登记到 `evidence/P0/external-acceptance-results.json`，证据文件放入对应的 `evidence/P0/external/<AT-ID>/` 目录，然后重新生成 `evidence/P0/acceptance-matrix.csv` 并运行 release gate。

除 UAT 外，当前 release gate 还缺少两个外部发布输入，但它们不计入上述 87/89 项 UAT：

- 非 example 的生产签署文件：`P0_SIGNOFF_FILE`；
- 非 example 的生产配置快照：`P0_CONFIG_SNAPSHOT_FILE`。

自动测试、合成 evaluator 输入、Bot 探针或 Codex 执行记录不能替代真实用户、多角色人员、真实 Discord/Railway 环境和具名签署。
